# Flow Horror Bot

بوت يوتيوب شورتس أوتوماتيكي يومي: يولّد قصة رعب أصلية بالذكاء الاصطناعي، يحولها لصوت، يركّبها على خلفية فيديو مناسبة، ويرفعها على قناة يوتيوب منفصلة.

## الفرق عن Flow Quran Bot الأصلي

| | القديم | الجديد |
|---|---|---|
| المحتوى | آيات قرآنية | قصص رعب أصلية (مولّدة بـ AI) |
| الصوت | تلاوة API (alquran.cloud) | Edge-TTS مجاني |
| الخلفية | طبيعة هادئة | غابات/طرق ضبابية/أماكن مهجورة |
| القناة | القناة الأصلية | قناة جديدة منفصلة (توكن مختلف) |

## الإعداد المطلوب (GitHub Secrets)

اذهب لـ Settings > Secrets and variables > Actions في الريبو، وأضف:

1. **`TOKEN_BASE64_HORROR`** — توكن OAuth لقناة اليوتيوب **الجديدة** (نفس طريقة توليد التوكن القديمة بالظبط، لكن لازم تسجل دخول بالقناة الجديدة وقت الـ OAuth flow، مش القديمة).
2. **`PEXELS_API_KEY`** — نفس المفتاح المستخدم في المشروع القديم (مجاني من pexels.com/api).
3. **`OPENROUTER_API_KEY`** — مفتاح مجاني من openrouter.ai لتوليد نص القصة. اعمل حساب، وخد الـ API key من الداشبورد.

## متغيرات اختيارية

- `TTS_VOICE_OVERRIDE`: يغيّر صوت edge-tts المستخدم في كل الأنواع دفعة واحدة (افتراضي `ar-EG-ShakirNeural` للرعب/اللغز و`ar-EG-SalmaNeural` للمعلومات). ده أصلاً محرك Azure النيورال بتاع مايكروسوفت مجاني تمامًا وبدون أي حساب، وفيه أصوات عربي كتير غير المصري تستاهل تجربها زي: `ar-SA-HamedNeural`، `ar-SA-ZariyahNeural`، `ar-JO-TaimNeural`، `ar-LB-RamiNeural`، `ar-KW-FahedNeural`، `ar-QA-MoazNeural`.
- `USE_PIPER=true`: يفعّل محرك [Piper](https://github.com/rhasspy/piper) — مفتوح المصدر بالكامل (MIT)، شغّال محلي، **بدون أي حساب أو مفتاح API أو دفع**. مش مضمون يبقى أحسن من edge-tts (edge-tts أصلًا محرك Azure الاحترافي مجاني)، لكنه تكنولوجيا مختلفة تمامًا تستاهل تجربة. لو فشل التحميل أو التشغيل لأي سبب، الكود بيرجع تلقائي لـ edge-tts من غير ما يبوّظ الفيديو. الصوت الافتراضي `ar_JO-kareem-medium` قابل للتغيير عبر `PIPER_VOICE_NAME` (لو غيّرته لازم تضيف رابط تحميله في `PIPER_VOICE_URLS` جوه main.py).
- `ELEVENLABS_API_KEY` + `ELEVENLABS_VOICE_ID`: لو قررت يومًا إن التكلفة مقبولة مقابل جودة/تعبير أعلى بكتير — مش مجاني بالكامل، فيه كوتة شهرية مجانية بس بعدها بيتحاسب. اختياري تمامًا ومش لازم تستخدمه.
- `OPENROUTER_MODEL`: الموديل المستخدم لتوليد القصة (افتراضي `google/gemini-2.0-flash-exp:free`). راجع openrouter.ai/models للموديلات المجانية المتاحة حالياً — القائمة بتتغير باستمرار.

## تشغيل يدوي محلي

```bash
pip install -r requirements.txt
export TOKEN_BASE64_HORROR=...   # أو صدّرها باسم TOKEN_BASE64 قبل التشغيل
export PEXELS_API_KEY=...
export OPENROUTER_API_KEY=...
python main.py
```

## ملاحظات مهمة قبل ما تشتغل بيه فلوس

- **المحتوى مولّد بالكامل بالـ AI** ومش منسوخ من Reddit أو أي مصدر — ده مهم عشان تتجنب مشاكل حقوق النشر والـ Content ID على يوتيوب.
- خلي بالك من **سياسة يوتيوب لمحتوى الرعب/الصادم**: لازم توضح في العنوان/الوصف إن القصص خيالية (موجود في الـ description templates)، وابتعد عن أي عنف صريح أو محتوى مقزز عشان القناة متتعملهاش Demonetize أو Age-restriction.
- شروط **YPP (برنامج شركاء يوتيوب)** بتتغير من وقت للتاني، وفيه كلام كتير عن محتوى "mass-produced/repetitive" (المحتوى المُعاد إنتاجه بشكل نمطي) إنه ممكن يتأثر بالتصنيف أو الأهلية للربح. يفضل تتابع آخر تحديثات يوتيوب لسياسة "Inauthentic content" بنفسك قبل ما تعتمد كلياً على القناة دي كمصدر دخل.
- جرّب تشغّل الفيديو الأول يدوي (`workflow_dispatch`) وشوف الناتج كويس قبل ما تسيبه أوتوماتيك يومي.
